# i18n 規範

## Key 命名格式（本專案實際慣例）

語系 key 是**扁平的 `snake_case`**，偶爾依功能巢狀分組（例如彈窗文案集中在 `alert.title.*`、`alert.text.*`）。**沒有**像 `LABEL.`/`MESSAGE.`/`TITLE.` 這種強制前綴規範，新增 key 時比照鄰近既有 key 的命名方式即可：

```json
{
  "add_job_id": "工作ID",
  "alert_desc": "告警說明",
  "alert": {
    "title": { "ok": "成功", "confirm": "確認", "error": "失敗" },
    "text": { "actions": "確定要{{ statusText }}這些 API？" }
  }
}
```

新增 key 時：
- 一般欄位標籤、按鈕文字：直接用扁平 `snake_case`（例：`client_name`、`cfm_del_client`）
- 特定功能一組相關文案較多時（如某個 alert/confirm 對話框），可仿照 `alert.*` 巢狀分組，但不要為單一 key 新建一層巢狀。

## 語系檔案

位於 `src/assets/i18n/`，共四份，**單層結構**（不像部分其他專案有「套件層 + 專案層」兩層合併機制）：

```
src/assets/i18n/
├── zh-tw.json   ← 繁體中文（本專案主要語言）
├── zh-cn.json   ← 簡體中文
├── en-us.json   ← 英文
└── ja.json      ← 日文
```

新增或調整任何一個 key 時，**必須同步更新這四份檔案**，避免缺漏語系在執行期顯示原始 key 字串。

## 在 Template 中使用

```html
<!-- pipe 寫法（最常見） -->
<button>{{ 'cancel' | translate }}</button>
<app-search-input placeholder="{{ 'fun_code' | translate }}" />
```

## 在 Script 中使用（`ToolService.getDict`）

大量業務邏輯（彈窗標題、動態組字串）透過 `ToolService.getDict()` 一次取得多個 key 對應的翻譯物件，而非逐一呼叫 `translate.get()`：

```ts
// ToolService 內部：
// async getDict(codes: string[], params?: object) { return await this.translate.get(codes, params).toPromise(); }

const dict = await this.toolService.getDict(['button.manager_oauth_group']);
this.dialogService.open(ManagerGroupListComponent, { header: dict['button.manager_oauth_group'] });

const dicts = await this.toolService.getDict(['cfm_del_client', 'client_id', 'client_name']);
this.confirmationService.confirm({
  header: dicts['cfm_del_client'],
  message: `${dicts['client_id']}:${this.clientDetail!.clientID}`,
});
```

- 需要**多個** key 且要組成訊息字串時，優先用 `toolService.getDict([...])`，一次取回物件後用 key 索引，不要為每個 key 各別呼叫一次 `translate.get()`。
- 若只需要單一即時翻譯，也可直接注入 `TranslateService` 使用 `this.translate.get('key').subscribe(...)` 或 `this.translate.instant('key')`。

## 插值語法

沿用 `@ngx-translate/core` 的 `{{ paramName }}` 插值，搭配 `getDict(codes, params)` 的 `params` 參數傳入變數：

```json
"actions": "確定要{{ statusText }}這些 API？"
```

```ts
const dict = await this.toolService.getDict(['actions'], { statusText: '啟用' });
```

## 確認 i18n key 同步的方式

新增/修改 key 後，提交前確認四份語系檔都有對應 key（可用文字搜尋工具比對四份檔案的 key 是否一致），缺漏的語系在執行期會直接顯示原始 key 字串而非翻譯內容。

## 常見錯誤

```html
<!-- ❌ 錯誤：硬編碼中文字串 -->
<button>取消</button>

<!-- ✓ 正確：使用 i18n key -->
<button>{{ 'cancel' | translate }}</button>
```

```ts
// ❌ 錯誤：只更新 zh-tw.json，忘記同步其餘三份
// ✓ 正確：zh-tw.json / zh-cn.json / en-us.json / ja.json 一併更新
```
